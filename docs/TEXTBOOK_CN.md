# 中文国际象棋规则教材

教材不是规则函数目录，而是“局面—问题—候选—证书—结果”的学习系统。

## 十五章

1. 完整局面与 FEN；
2. 可读走法记录、完整证书与稀疏后继；
3. 车、象、后与阻挡；
4. 马、王与受攻击格；
5. 兵的普通规则；
6. 升变、吃过路兵和易位；
7. 将军与三类应将；
8. 绝对/相对牵制；
9. 闪击、闪将和双将；
10. 将死、逼和与合法着集合；
11. 单马、单象、双马和材料死局；
12. 重复、五十/七十五回合和棋局事件；
13. 王车、王后杀王方法；
14. 互动基础残局；
15. Agent 记录、完整证书和可信边界。

## 局面实验

实验锁定一个局面和教学目标，可显示：

- 正方形迷你棋盘；
- 允许操作的棋子、路径、阻挡、攻击者和目标；
- 走前、机械候选和实际提交局面；
- 稀疏格子编辑与精确棋盘码；
- FEN 字段变化；
- 王安全和战术效果；
- 真实 Litex 源码、判定和诊断。

被拒绝的候选仍用于解释，但不会替换当前局面。

## 教材与工作台

每个适合继续操作的局面可以携带 FEN、标题、目标和返回地址打开工作台。两侧共用同一 API、`Position`、查询生成器和 Litex 门禁。

## 源码镜像

`textbook/chess_rules_textbook_cn.lit` 由同步脚本从 `formal/chess_rules.lit` 生成。中文注释可以变化，非注释定义必须逐行一致；教学正例位于明确的 examples 分界之后。
