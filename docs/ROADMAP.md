# Roadmap after v0.8

1. Move more attack/path relations from host-side enumeration into reusable Litex relations.
2. Explore a formal finite-map board with checked `update` and extensionality, then compare its cost with the exact sparse-code design.
3. Add differential perft coverage beyond depth 2 and a larger corpus of special-position tests.
4. Formalize repetition/history predicates rather than only aggregating them in Python.
5. Add guided multi-step endgame objectives, mistake classification and optional tablebase comparison clearly separated from legality authority.
6. Define a stable machine-readable Agent trace schema beside the human-readable Litex record.
